## 한 번의 기술 개선

`official-source-lib.mjs`와 `trust-status-lib.mjs`의 비교 정규화를 `trust-v2`로 바꿨다. 비교 전에 유니코드 호환형을 정규화하고, 공백·문장부호·기호를 제거하며, 시작일·종료일의 `YYYY.MM.DD`, `YYYY/MM/DD`, `YYYY-MM-DD` 구분자를 ISO 형식으로 맞춘다. 이는 행사명·장소의 단어를 삭제하거나 주소 별칭을 추측하지 않는 표기 동등성만 처리한다. 공식성 기준, 접근 실패 처리, 핵심 필드 요구 조건, 변경됨 판정은 완화하지 않았다.

## 해결하지 못한 이유

- 공식 URL 자체가 없거나 행사·운영기관 관계를 증명할 수 없다.
- 403·429·timeout·기타 HTTP 오류는 차단 우회나 공격적 재시도를 하지 않고 확인 필요로 유지했다.
- 접근 가능한 페이지라도 해당 회차의 핵심 필드가 명시되지 않으면 비교할 수 없다.
- 장소·시설 표현이 다를 때 동일 장소인지 이전인지 근거가 없으면 자동 추론하지 않는다.
- 블로그·카페·뉴스·티켓 판매처·광고·개인 SNS를 공식 근거로 승격하지 않는다.
