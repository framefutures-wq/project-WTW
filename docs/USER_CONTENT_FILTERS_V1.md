# 사용자 콘텐츠 필터 v1

## 결정 범위

운영 D1과 운영 API를 조회하지 않고 기존 fact-tag dry-run artifact
`.wrangler/fact-tag-dry-run.json`을 분석했다. 이 snapshot은 행사 263건을 기준으로 하며, 생성 시각은 `2026-09-19T13:37:37Z`이다. TourAPI sync 완료 시각은 `2026-09-18T21:00:20Z`, 공식 링크 확인 최신 시각은 `2026-09-19T03:52:35Z`다.

현재 Worker의 `theme` query 계약은 `food`, `fireworks`, `flowers`, `experience`, `performance`만 허용한다. 따라서 백엔드가 지원하지 않는 필터를 화면에 추가해 결과가 나오는 것처럼 만들지 않았다.

## snapshot 후보 비교

추가 후보의 fact-tag 행사 수는 전시 117(44.5%), 전통·역사 93(35.4%), 자연 59(22.4%), 스포츠 47(17.9%), 퍼레이드 37(14.1%), 야경·빛 28(10.6%), 사진 콘텐츠 33(12.5%)였다. 빈도만 보면 전시·전통·자연은 의미가 있지만 현재 API query가 지원하지 않으므로 v1 화면에는 보류한다.

내부 편의·대상 태그는 콘텐츠 필터가 아니다. 실내 8, 셔틀 2, 접근성 1, 좌석 2, 반려동물 가능 1은 상세·향후 편의 필터·동행 판단에 남긴다. 주차와 반려동물 동반 불가는 운영 v1 제외 상태를 유지한다.

## overlap 판단

snapshot에서 주요 교집합은 공연∩야경·빛 26건, 꽃∩자연 13건, 먹거리∩지역특산물 29건, 전시∩전통·역사 52건, 체험∩교육 38건, 체험∩어린이 프로그램 10건이다.

- 공연과 야경·빛은 의도가 다르지만 야경·빛은 현재 query 미지원이라 보류한다.
- 꽃과 자연은 겹치지만 꽃은 식물·정원 콘텐츠를, 자연은 숲·생태·경관을 찾는 의도가 달라 별도 후보로 유지한다.
- 지역특산물은 음식이 아닌 농산물·시장·판매까지 포함할 수 있어 먹거리에 자동 OR로 묶지 않는다.
- 전시와 전통·역사, 체험과 교육도 의미가 달라 각각 향후 후보로 둔다.
- children/family/education는 `누구와` 또는 프로그램 성격과 역할이 겹치므로 첫 화면 콘텐츠 필터로 추가하지 않는다.

## 선택 방식과 “모두”

현재 구조와 빠른 탐색 목적에 맞춰 `무엇을`은 단일 선택을 유지한다. 한 행사가 여러 fact-tag를 갖는 것은 정상이며, 사용자가 한 콘텐츠 의도를 고르고 결과를 빠르게 좁히는 흐름을 우선한다. 선택을 다시 누르거나 `모두`를 누르면 콘텐츠 조건이 제거된다. `모두`는 모든 태그의 OR가 아니라 query를 보내지 않는 상태다.

## 모바일 검토

기존 chip wrap 스타일을 유지하는 360px, 390px, 430px 기준으로 6개 항목이 가로 스크롤 없이 줄바꿈된다. 긴 내부 이름을 사용자에게 노출하지 않으므로 chip은 짧은 한글 문구로 유지된다. 선택 상태는 색상과 `aria-pressed`로 함께 전달된다.

## 제외·향후 후보

- 이번 v1 제외: 전시, 야경·빛, 자연, 전통·문화, 스포츠, 퍼레이드, 사진 콘텐츠. 모두 의미와 snapshot coverage는 있으나 현재 Worker query 계약 확장이 필요하다.
- 먹거리와 지역특산물의 통합, 사진 콘텐츠 독립 필터는 오탐·사용 의도 차이를 확인한 뒤 결정한다.
- 향후 “더보기” 후보: 전시, 자연, 전통·문화, 스포츠, 퍼레이드. 야경·빛은 별도 운영 시간 정보와 혼동하지 않도록 콘텐츠 근거를 유지해야 한다.
- convenience tag(`indoor`, `shuttle`, `accessibility`, `seated_viewing`, `pet_allowed`)는 콘텐츠 카테고리에 넣지 않는다.

## 백엔드 연결 시 남은 작업

현재 UI는 기존 `theme` query 값을 그대로 사용한다. 향후 추가 필터를 운영에 연결할 때는 Worker validation, D1 query, API metadata, 회귀 테스트를 함께 확장해야 하며, 그 전까지는 UI에 노출하지 않는다. 이번 작업에서는 backend, schema, 운영 D1, companion suitability를 변경하지 않았다.
