재현: `npm ci`, `npm run setup`, `npm run check`, `npm run dev` 후 별도 터미널에서 `npm run test:smoke`, `npm run test:ui`. 브라우저 최초 준비는 `npx playwright install --with-deps chromium`입니다. 브라우저 화면 캡처는 git에서 제외되는 `test-results/discovery-desktop.png`, `test-results/discovery-mobile.png`에 생성됩니다.

현재 행사 목록은 전부 가상 샘플입니다. 실제 행사 정확성·TourAPI 계약·외부 수집·원격 D1·배포·실시간 취소 확인은 이번 단계의 검증 범위에 포함되지 않습니다. TourAPI Secret 값은 입력하지 않았습니다.

## 실행 중인 앱 전체 브라우저 재검증

`http://127.0.0.1:8787`에서 실행 중인 앱을 그대로 검사했습니다. 데이터 재생성이나 앱 코드 변경 없이 기존 로컬 D1을 읽었습니다. 실제 Chromium에서 데스크톱 1440×1000, 모바일 390×844(터치·모바일 모드)로 총 24개 테스트가 모두 통과했습니다(57.6초). TypeScript 검사와 HTTP smoke 검사도 통과했습니다.

| 요청 항목                    | 확인 결과                                                                                                                                       |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 데스크톱 화면                | 카드·상세 창·닫기·Escape·포커스 복귀 정상, 가로 넘침 없음                                                                                       |

복합 필터·필터 초기화·없는 검색어·위치 정렬·위치 사용 해제도 정상입니다. 브라우저에서 목록/상세 API에 의도적인 503 응답을 주입해 오류 안내와 재시도 복구를 확인했습니다. 이전 지역 요청을 지연시켜도 최신 선택의 결과가 유지됩니다.

앱 기능 오류는 발견하지 않았습니다. 추가 테스트에서 스크린리더용 문구와 화면용 문구가 중복 매칭되는 검사 선택자를 보정했고, JSON 응답 검사 타입을 명시했습니다. 재검증 가능한 전체 검사 코드는 `tests/browser/full-validation.spec.ts`에 추가했습니다.

재현은 서버가 실행 중인 상태에서 `npm run test:ui`입니다. 최종 기계 판독 결과는 `test-results/browser-report.json`, 전체 화면 캡처는 `test-results/full-desktop.png`, `test-results/full-mobile.png`입니다. 이 파일들은 Git에 포함하지 않습니다.
