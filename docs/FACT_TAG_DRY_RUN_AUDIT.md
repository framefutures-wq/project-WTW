## deterministic 판정 규칙

태그는 제목 또는 저장된 상세의 명시적 단어가 같은 문맥에 있을 때만 후보로 만들었다. 프로그램/반복정보는 `program_level`, 제목·overview·eventplace는 `event_level`로 기록하고, 나머지는 `scope_unknown`으로 남겼다. 동일 행사·태그는 하나로 deduplicate했다. 주소와 공통 페이지 문구는 콘텐츠 근거로 사용하지 않았다.

부정 표현(불가·금지·운영하지 않음·폐지·프로그램 종료)은 긍정 후보에서 제외했다. 우천·기상·변경 가능·매주·회차·특정일 같은 문구는 후보를 유지하되 조건부로 별도 집계했다. 긍정과 부정이 함께 남은 경우 자동 해소하지 않고 conflict로 남겼다.

- 조건부 프로그램 후보: **33건**. 대표 사례는 새연교 불꽃쇼(매주 금·토), 나오라쇼(공연일·휴장 기간), 광안리 드론쇼(기상에 따라 일정 변경)처럼 프로그램 존재는 확인되지만 행사 전체 기간으로 일반화할 수 없는 경우다.
- 부정 또는 종료 표현으로 제외된 근거: **5건**.
- 충돌 후보: **5건**. 왕가의 산책의 전시장·행렬 표현처럼 서로 다른 TourAPI 상세 필드에서 같은 단어의 문맥이 충돌하거나, EX펌킨나잇처럼 일반 체험과 특정 대상 체험 제한이 함께 나타난다. 이들은 자동 확정 전에 사람이 확인해야 한다.
- 날짜 한정 프로그램 근거: **51건**. 현재 schema에는 valid_from/valid_to를 추가하지 않았고, 이번 감사에서는 program_level과 원문 문구만 보존했다.

특히 `pet_allowed`는 1건만 명시 근거가 있었고 `pet_not_allowed`는 0건이었다. 야외·공원이라는 이유로 반려동물 태그를 만들지 않았다.

## 무태그 행사 원인

| 유형 | 행사 수 | 대표 사례 |
|---|---:|---|
| A. 공식 원본 설명 부족 | 18 | 완주 와일드&로컬푸드축제, 설악문화제, 정조효문화제, 군산시간여행축제, 안흥찐빵축제 |
| B. 텍스트는 있으나 현재 태그 체계와 일치하지 않음 | 2 | 호캠프 리턴즈, 2026 숭례문 파수의식 |
| C. 특징은 있으나 deterministic 확정 불가 | 0 | 없음 |
| D. 기술적 추출 문제 | 0 | 식별된 사례 없음 |
| E. 기타 | 0 | 식별된 사례 없음 |

이번 스냅샷에서는 별도 추출 실패 표지가 저장되어 있지 않아 D를 추측해 늘리지 않았다. A는 제목 외에 충분한 저장 프로그램/설명 텍스트가 없는 경우이며, B는 `호캠프 리턴즈`, `2026 숭례문 파수의식`처럼 저장 텍스트가 있어도 현재 목록의 사실 태그 정의와 직접 일치하지 않는 경우다. deterministic 규칙만으로 남은 AI 보완 후보는 **0건**으로 집계했다. 원본이 부족한 행사에 AI를 적용하는 것은 부적절하다.

## 추가 태그 후보

반복적으로 보이는 `캠핑/숙박`, `예약·사전신청 필요`, `시장·판매`, `해설/투어`, `야간 운영 시간`은 향후 검색 가치가 있어 보인다. 다만 현재 목록과 의미가 겹치거나 시간·예약 조건의 유효기간 관리가 필요하므로 이번 dry-run에서 운영 태그로 확정하지 않았다.

## 운영 적용 전 수정할 점

- 공식 페이지의 공통 메뉴·footer·관련 콘텐츠를 행사 본문으로 오인하지 않도록 본문 범위 저장이 먼저 필요하다.
- program_level 후보에 날짜·회차·조건을 함께 보존할 별도 근거 구조가 필요하다. 이번 단계에서는 schema를 바꾸지 않았다.
- `sports`처럼 장소명에 포함된 단어가 콘텐츠로 승격되지 않도록 필드 제한을 유지해야 한다.
- 긍정/부정 충돌은 자동 태그로 운영하지 말고 검토 큐로 보낸다.
- 이 결과는 dry-run 후보이며 `events`, `event_tags`, `event_evidence`, 신뢰상태, 공식 감사 기록을 수정하지 않았다.
