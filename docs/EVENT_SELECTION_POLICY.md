# 행사 선별 정책 v1

## 서비스 정의

주말뭐해?는 전국의 모든 행사를 최대한 많이 보관하는 데이터베이스가 아니라, 사용자가 “이번 주말 뭐하지?”에 답할 수 있도록 공개 행사를 고르는 서비스다. 행사 정보의 양, 조회수, 예상 방문객 수는 선별 가치의 대리 지표로 사용하지 않는다.

기본 흐름은 `발견 → 선별 → 통과 행사 상세정보 보강 → 공식 확인 정보만 노출`이다. TourAPI는 기본 공급원으로 유지하며, 지자체 공식 정보는 TourAPI가 놓친 통과 후보를 제한적으로 보충하는 근거다.

## 공개 상태

### MAIN

일반 목록과 검색에서 보인다. 다음을 모두 만족해야 한다.

- 행사명, 실제 방문 날짜, 실제 방문 장소가 TourAPI 또는 주최·지자체 공식 자료로 확인된다.
- 일반인이 참여 또는 관람할 수 있다.
- 축제·거리행사·야간행사·시즌행사·불꽃/드론쇼·퍼레이드·시민 공개 공연·가족 체험처럼 이번 주말에 외출 후보로 고려할 이유가 있다.
- 지역 대표성, 여러 프로그램의 결합, 특별한 기간성, 관광 목적 중 하나 이상을 공식 내용으로 확인할 수 있다.

규모나 정보량이 작아도 위 조건을 충족하면 MAIN이 될 수 있다. 반대로 큰 행사처럼 보이더라도 방문 가능 여부 또는 기본정보가 확인되지 않으면 MAIN으로 두지 않는다.

### NEARBY_ONLY

공개·방문 가능하고 최소 기본정보는 충족하지만, 전국 일반 목록보다 근처 사용자에게 더 적합한 행사다.

- 동네 단위 공개 공연, 소규모 체험, 지역 주민 중심 행사, 정기 가이드 투어처럼 목적지로 장거리 이동할 근거가 약한 경우
- 해당 장소 또는 인근에 있는 사용자는 주말 외출 후보로 고려할 수 있는 경우

작다는 이유만으로 EXCLUDE하지 않는다. MAIN과 NEARBY_ONLY의 차이는 정보량이 아니라 전국 일반 목록에서의 탐색 적합성이다.

### EXCLUDE

주말 외출 추천의 단발·공개 행사라는 성격에 맞지 않거나 최소 기본정보가 없는 항목이다.

- 주민센터 정규 강좌, 도서관 정기 수업, 설명회·세미나, 기관 내부행사, 회원 전용 행사
- 모집·접수 공지, 온라인 행사, 상품 할인·매장 판촉, 일반 상시 프로그램
- 계절·특별 행사와 구분되지 않는 상설 상업 공연 또는 시설의 일상 영업
- 행사명·날짜·실제 방문 장소 중 하나라도 공식적으로 확인되지 않는 경우

예약이 필요하다는 사실만으로 EXCLUDE하지 않는다. 일반인이 방문할 가치가 있는 예약형 체험·투어는 MAIN 또는 NEARBY_ONLY가 될 수 있다.

### REVIEW

REVIEW는 audit용 보류 상태이며 공개 상태가 아니다. 다음 상황에서만 사용한다.

- 공식 자료 간 날짜·장소·공개 여부가 충돌한다.
- 행사인지 정규 강좌·상설 영업인지 구분할 수 없다.
- 동일 이름의 다른 연도·다른 프로그램 자료가 섞일 위험이 있다.

보류를 억지로 공개 상태로 바꾸지 않는다.

## 상세정보 정책

선별 결과와 상세정보 깊이는 별개다. 공식정보가 적은 통과 행사는 행사명, 날짜, 장소, 문의, 공식 안내와 이미지가 있을 때의 이미지만 보여도 정상이다. summary, highlights, 운영시간, 주요 일정, 프로그램은 공식 근거가 있을 때만 추가하며 빈 필드와 섹션은 숨긴다.

행사 전체 운영시간과 프로그램 시간은 계속 분리한다. 행사 전체 운영시간만 카드와 상세 기본정보에 표시한다. 불꽃·공연·퍼레이드처럼 개별 프로그램의 시간은 상세 주요 일정 또는 프로그램에만 표시한다.

## TourAPI와 지자체 보충

TourAPI의 기존 행사를 버리거나 전체 재구축하지 않는다. TourAPI에 없는 후보도 다음을 모두 충족할 때만 지자체 공식 자료로 보충 후보가 될 수 있다.

1. 주최·지자체 공식 자료로 행사명·날짜·실제 방문 장소를 확인한다.
2. MAIN 또는 NEARBY_ONLY 선별 기준을 통과한다.
3. 기존 TourAPI 행사와 중복 여부를 좁게 검토한다.
4. 등록 전에는 공식 근거와 후보 판정을 사람이 검토한다.

이번 정책은 전국 지자체 크롤러, 자동 선별 엔진, 신규 public filter, Cron 또는 production write를 만들지 않는다.

## 예외와 재검토

- 특정 지역의 작은 행사가 프로그램·공개성·기간성으로 주말 목적지가 될 수 있으면 MAIN을 허용한다.
- 반복 투어는 정기적이라는 이유만으로 EXCLUDE하지 않지만, 장소 인근에서의 가치가 중심이면 NEARBY_ONLY를 우선 검토한다.
- 상설 공연은 특별 시즌·지역 축제·공공 공개 행사와 결합된 근거가 있을 때만 개별적으로 재검토한다.
- 정보가 적다는 이유만으로 EXCLUDE하지 않는다.
