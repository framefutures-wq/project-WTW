## 251과 234의 의미

251은 원격 D1의 TourAPI 고유 행사 수다. 234는 이전 로컬/공개 비교의 API 검증 요청 수로, 행사 수가 아니다. 따라서 251 − 234 = 17을 누락 행사 수로 해석할 수 없으며, 누락 17건이라는 집합은 존재하지 않는다.
