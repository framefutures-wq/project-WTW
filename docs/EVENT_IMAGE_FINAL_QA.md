## 브라우저 QA

공개 URL에서 데스크톱과 모바일 브라우저를 각각 검사했다.

- 카드 2페이지씩 총 18개 행사 이미지: 모두 `naturalWidth > 0`
- 상세 이미지: 데스크톱·모바일 모두 로딩 성공
- 이미지 실패 synthetic 경로: 9개 카드가 기존 플레이스홀더로 정상 fallback
- CSP 콘솔 오류: 없음
- 이미지가 카드 밖으로 넘침: 없음
- lazy loading과 상세 전환: 정상

현재 `object-fit: cover` 정책은 유지한다. 시각 QA에서 소수 포스터의 좌우 정보가 잘릴 수 있는 사례는 관찰됐지만, 공통 정책을 `contain`으로 바꾸거나 Cloudflare Image Transformations를 도입할 정도의 반복적인 품질 문제는 아니다. 향후에는 이미지 유형 근거가 저장되는 시점에 한해 포스터/그래픽에만 선택적인 표시 정책을 검토할 수 있다.
